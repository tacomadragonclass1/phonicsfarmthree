## 1. `Emitter<Events>` (src/core/Emitter.ts)
`export class Emitter<Events> implements EventSource<Events>` (from contracts).
- `on(event, listener)` returns an `Unsubscribe`. Calling it twice is harmless.
- `emit(event, payload)`. For events whose payload type is `void`, the call
  site must be able to write `emitter.emit('sequenceFinished')` with no
  second argument -- solve this in the type signature, not with `any`.
- Listeners run in subscription order. A listener that throws must not stop
  the others; collect the error and rethrow the FIRST one after all ran.
- A listener removed during an emit is not called later in that same emit;
  a listener added during an emit is not called until the next emit.
- `clear()` removes every listener.
No imports from three.js or the DOM.

## 2. `math.ts` -- pure functions, no three.js import
All angles in radians.
- `clamp(v, lo, hi)`
- `lerp(a, b, t)`
- `damp(current, target, rate, dt)`: frame-rate independent exponential
  approach, `current + (target - current) * (1 - exp(-rate * dt))`.
- `moveToward(current, target, maxDelta)`: never overshoots.
- `wrapAngle(a)`: into (-PI, PI].
- `angleDelta(from, to)`: shortest signed difference, in (-PI, PI].
- `dampAngle(current, target, rate, dt)`: `damp` along the shortest arc,
  result wrapped.
- `yawFromDirection(x, z)`: `Math.atan2(x, z)` (yaw 0 faces +Z).
- `directionFromYaw(yaw)`: returns `{ x: sin(yaw), z: cos(yaw) }`.
- `rotateY(x, z, angle)`: rotates the horizontal vector (x, z) about +Y by
  `angle` (right-handed, Y up): returns
  `{ x: x*cos + z*sin, z: -x*sin + z*cos }`.
- `horizontalDistance(a: Vec3, b: Vec3)`: ignores y.
- `limitLength2(x, y, max)`: returns `{x, y}` scaled so its length <= max.
