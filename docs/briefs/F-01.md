## `FindRules`
```ts
export class FindRules implements EventSource<FindEvents> {
  constructor(options: {
    /** Live array of every block. */
    blocks: readonly BlockState[];
    sound: SoundPlayer;
    /** The block in Chuck's hands right now, or null. */
    carried: () => BlockState | null;
    /** Returns a number in [0, 1). Default Math.random. */
    random?: () => number;
    /** Sound keys. Defaults: ask 'annette_find', praise 'annette_good'. */
    askKey?: string;
    praiseKey?: string;
  });
  /** The letter she is waiting for, or null before the first request. */
  readonly wanted: string | null;
  /** Chuck pressed the action in front of her. */
  talk(): void;
  on(...): Unsubscribe;
}
```
`talk()`:
- **Nothing wanted yet** (first talk, or after a find): choose a letter and
  ask. Choosing: the distinct letters of `blocks`, sorted, excluding the
  letter of the carried block (if any) and excluding the PREVIOUS wanted
  letter when more than one choice remains; pick
  `choices[Math.floor(random() * choices.length)]`. No blocks => do nothing.
  Asking = `sound.playSequence([askKey, letter])` and emit `asked`.
- **Wanted, hands empty**: repeat the request (same letter): play
  `[askKey, letter]`, emit `asked`.
- **Wanted, carrying the wanted letter**: play `[praiseKey]`, emit `found`
  `{ letter, blockId }`, and clear `wanted` (the next talk asks for a new
  one; remember this letter as the previous one).
- **Wanted, carrying another letter**: play `[brought, askKey, wanted]`
  (she says the sound he brought, then asks again) and emit `tryAgain`.
It never listens to the sound player's events.

## Tests
1. first talk asks: plays ['annette_find', X] and emits `asked` with X, `wanted` is X.
2. with `random: () => 0` and blocks s, a, t the first letter is 'a' (sorted).
3. hands empty, talk again => same letter asked again.
4. carrying the wanted block => plays ['annette_good'], `found` with the block id, `wanted` null.
5. carrying another => plays [brought, 'annette_find', wanted], `tryAgain`, `wanted` unchanged.
6. after a find the next request is never the same letter (random 0 and random 0.99, three blocks).
7. the first request is never the carried block's letter.
8. one block only: it is asked again after being found (no other choice).
9. no blocks: talk does nothing and plays nothing.
10. duplicate letters in `blocks` count once.
