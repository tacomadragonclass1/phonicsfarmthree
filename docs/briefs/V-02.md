## 1. `FindRules` changes
The blocks array is LIVE: the game removes a block from it when it is
found. Always read it at the time of use.
- New method `begin(): void` -- she makes her first request without being
  talked to (same as the "nothing wanted yet" branch of `talk()`); does
  nothing if something is already wanted.
- New method `next(): void` -- called by the game AFTER it has removed the
  found block. If letters remain: choose (same rule as before) and play
  `[praiseKey, askKey, letter]`, emit `asked`. If none remain: play
  `[praiseKey]` and emit `complete`.
- `talk()` when the right block is carried: emit `found` and clear `wanted`
  as now, but play NOTHING (the game calls `next()`, which speaks).
- New read-only `done: boolean` -- true once `complete` has been emitted;
  after that `talk()`, `begin()` and `next()` do nothing.
- Everything else as it is. Update the tests; add: begin asks; next after
  removal asks a remaining letter with praise first; next with nothing left
  plays [praise] and emits complete once; talk after done is silent.
