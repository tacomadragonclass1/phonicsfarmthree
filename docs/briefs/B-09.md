# Task B-09: the look -- painted surface, ink outline, lighting

Read `AGENTS.md` first and follow it.
Base-colour textures loaded by GLTFLoader are already tagged sRGB; do not
decode them by hand.

Noise functions to use (GLSL, copy exactly):
```glsl
float hash13(vec3 p) {
  p = fract(p * 0.1031);
  p += dot(p, p.zyx + 31.32);
  return fract((p.x + p.y) * p.z);
}
float vnoise(vec3 p) {
  vec3 i = floor(p); vec3 f = fract(p);
  f = f * f * (3.0 - 2.0 * f);
  float n000 = hash13(i),                 n100 = hash13(i + vec3(1,0,0));
  float n010 = hash13(i + vec3(0,1,0)),   n110 = hash13(i + vec3(1,1,0));
  float n001 = hash13(i + vec3(0,0,1)),   n101 = hash13(i + vec3(1,0,1));
  float n011 = hash13(i + vec3(0,1,1)),   n111 = hash13(i + vec3(1,1,1));
  return mix(mix(mix(n000,n100,f.x), mix(n010,n110,f.x), f.y),
             mix(mix(n001,n101,f.x), mix(n011,n111,f.x), f.y), f.z);
}
```
Known traps: an outline pass that writes alpha < 1 drops out of the opaque
queue and silently never draws -- keep it opaque. An outline offset in MODEL
space is a fixed number of metres (fat on a berry, invisible on a house) --
it must be offset in CLIP space by a pixel count.

## `PaintedMaterial.ts`
`export function createPaintedMaterial(map: THREE.Texture, options?: { grainStrength?: number; grainScale?: number; grainWarm?: number; rimStrength?: number; rimPower?: number }): THREE.MeshToonMaterial`
Defaults: grainStrength 0.12, grainScale 7.5, grainWarm 0.5, rimStrength
0.16, rimPower 3.0.
- A `MeshToonMaterial` with `map`, and a 3-texel `gradientMap`
  (`DataTexture`, NearestFilter, values ~ 0.55 / 0.8 / 1.0 so shadow is a
  band, not black). Share ONE gradient texture between all materials.
- `onBeforeCompile`: add a world-position and world-normal varying in the
  vertex shader, and in the fragment shader, right after the base colour is
  read from the map (`#include <map_fragment>`), apply the patina: two octaves of value noise on
  `worldPos * grainScale` (0.65 + 0.35 with the 2.7x / +11.3 second octave),
  `n = (n - 0.5) * 2.0`, then
  `diffuseColor.rgb = clamp(diffuseColor.rgb * (1.0 + n * grainStrength) * mix(vec3(1.0), vec3(1.06, 1.0, 0.93), grainWarm * n), 0.0, 1.0)`.
- Rim: add to the emissive term
  `rimTint * pow(1 - clamp(dot(normal, viewDir), 0, 1), rimPower) * rimStrength * clamp(worldNormal.y * 0.5 + 0.5, 0, 1)`
  with rimTint (0.72, 0.82, 1.0). Find the right injection point
  (`#include <emissivemap_fragment>` is where `totalEmissiveRadiance` is
  final) by reading the shader source.
- Uniform values live in `material.userData.uniforms` so they can be tuned
  live; set `customProgramCacheKey` so all painted materials share a program.
- Skinned meshes must still work (do not break the skinning chunks).

## `InkOutline.ts`
`export function createInkMaterial(options?: { widthPx?: number; color?: THREE.ColorRepresentation; variation?: number }): THREE.ShaderMaterial`
Defaults 3.4 px, ink (0.13, 0.10, 0.09), variation 0.30.
- `side: THREE.BackSide`, opaque, no lights, `fog: false`, depthWrite true.
- Vertex: standard transform INCLUDING skinning and morph support (use the
  three.js chunks: `skinning_pars_vertex`, `skinbase_vertex`,
  `skinnormal_vertex`, `skinning_vertex`, `begin_vertex`, `beginnormal_vertex`,
  `defaultnormal_vertex`, `project_vertex` -- verify names in ShaderChunk).
  After projection, push `gl_Position.xy` along the normalised screen-space
  normal by `widthPx * gl_Position.w / resolution * 2.0`, `resolution` is a vec2 uniform in DEVICE pixels; widthPx is
  authored at a viewport height of 800 px, so also multiply by
  `resolution.y / 800.0`.
- Fragment: `cell = floor(worldPos * 9.0)`, `wobble = mix(1.0 - variation, 1.0, hash(cell))`,
  colour = `mix(vec3(0.55, 0.55, 0.52), ink, 0.94 * wobble)`, then convert
  to the output colour space with `#include <colorspace_fragment>`.
- `export function setInkResolution(material, width, height): void`.
- ONE shared ink material for the whole game (export a getter that creates
  it once).

`export function addOutline(mesh: THREE.Mesh | THREE.SkinnedMesh): THREE.Mesh`
creates the hull as a CHILD of `mesh` sharing its geometry (for a
SkinnedMesh: a SkinnedMesh bound to the SAME skeleton with the same
bindMatrix), `castShadow = false`, `receiveShadow = false`,
`userData.isOutline = true`, name `<mesh.name>_ink`. Returns the hull.

## `applyLook.ts`
`export function applyLook(root: THREE.Object3D, options?: { outline?: boolean }): void`
For every Mesh under `root` (skip ones with `userData.isOutline`): if its
material is a `MeshStandardMaterial` WITH a `map`, replace it with a painted
material built from that map (cache per source material uuid so shared
materials stay shared) and, unless `outline === false`, add an outline hull.
A material with NO map is left completely untouched (the block's cream
letter faces) and gets NO painted material -- but its mesh still gets no
hull either (the body mesh `Cube` carries the block's outline).
Idempotent: calling it twice must not add a second hull or re-wrap.

## `LightingRig.ts`
`export function createLightingRig(): { group: THREE.Group; sun: THREE.DirectionalLight; follow(target: THREE.Vector3): void }`
- Hemisphere light: sky (0.74, 0.83, 1.0), ground (0.55, 0.50, 0.42),
  intensity 1.15.
- Directional "sun": colour (1.0, 0.93, 0.80), intensity 1.9, direction from
  elevation 34 degrees, azimuth 40 degrees. castShadow, shadow map 2048,
  orthographic shadow camera +-20 m, near 1, far 80, bias -0.0004,
  normalBias 0.03.
- `follow(target)` re-centres the sun and its target on `target` (snapped to
  whole shadow texels to stop shimmer) so the shadow box travels with the
  player.
- Also export `export function configureRenderer(renderer: THREE.WebGLRenderer): void`:
  `outputColorSpace = SRGBColorSpace`, `toneMapping = NoToneMapping`,
  `shadowMap.enabled = true`, `shadowMap.type = PCFSoftShadowMap`, and
  `export function createFog(): THREE.FogExp2` with colour (0.80, 0.86, 0.90)
  and density 0.0045.

## Tests (Node, no WebGL -- test structure, not pixels)
applyLook replaces a mapped standard material with a MeshToonMaterial that
keeps the same map; leaves an unmapped material identical (same object);
two meshes sharing a material share the painted one; adds exactly one hull
per mapped mesh and none on the second call; the hull shares geometry and
is BackSide; a SkinnedMesh's hull shares its skeleton; the gradient texture
is shared; the ink material getter returns one instance;
`setInkResolution` updates the uniform; lighting rig has one hemisphere and
one shadow-casting directional light and `follow` moves both the light and
its target by the same offset.
