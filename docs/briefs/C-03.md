## `BellView implements Updatable, Disposable`
```ts
constructor(options: { position: Vec3; frame: THREE.Object3D; bell: THREE.Object3D; pivotHeight?: number })
readonly root: THREE.Group;        // at `position` (bottom centre of the frame)
setFocused(on: boolean): void;     // bell eases to scale 1.1 when lit, back to 1.0 (rate 14, `damp`)
ring(): void;                      // start a swing
update(dt: number): void;
dispose(): void;                   // removes root from its parent
```
- `frame` is added at local (0,0,0). `bell` is added at local
  (0, pivotHeight, 0), default `pivotHeight` 1.42 -- the bell model's origin
  is its pivot and it hangs below it.
- Swing: a damped oscillation of `bell.rotation.z`:
  `angle = 0.5 * exp(-2.2 * t) * sin(2 * PI * 1.6 * t)` with `t` = seconds
  since `ring()`. When `t > 3` set the angle to exactly 0 and stop.
  `ring()` during a swing restarts it (`t = 0`).

## `BlockView` additions (do not change existing behaviour)
```ts
/** A quick "this one is sounding" pop: the inner group jumps up 0.18 m and falls back over 0.35 s. */
pulse(): void;
/** Word made: three hops, 0.3 m high, 0.3 s each, starting after `delay` seconds. */
celebrate(delay?: number): void;
```
Both are driven from `update(dt)` and add a vertical offset on a NEW group
placed between `root` and the existing inner group (call it `lift`), so
they never fight the bob or the focus scale and `root.position` still
equals the game state. Hop shape: `height * sin(PI * u)` for `u` in 0..1.
Note `root.children[0]` must stay the group that carries the focus scale?
No: after this change `root.children[0]` is `lift` and `lift.children[0]`
is the inner group -- update the ONE existing test in `tests/views.test.ts`
that reads `root.children[0]` for the scale (you may edit that single test).
