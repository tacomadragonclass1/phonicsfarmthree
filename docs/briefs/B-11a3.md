## Tests to write (12, one assertion idea each)
BlockView (fake model: Group with a `Cube` mesh and five plane meshes named
Front/Right/Back/Left/Top, all sharing one `MeshStandardMaterial`):
1. `root.position` equals the state position after construction.
2. focus on + `update(0.1)` changes the Front panel material's colour; the
   original shared material's colour is unchanged.
3. focus off restores the panel colour exactly.
4. two views built from two models sharing one material have different
   panel materials.
5. after focus + several updates, `root.position` still equals the state
   position (the bob is on an inner group).
6. `attachTo(anchor)` puts root under the anchor at (0,0,0);
   `attachTo(null)` returns it to the original parent at the state position.
7. a model with only `Cube` does not throw on `setFocused(true)`.

PedestalView (post and cap are plain `THREE.Group`s):
8. post at local y 0.25, cap at 0.56, root at the state position.
9. focused + `update(0.2)` raises `cap.position.y` above 0.56; unfocused +
   ten `update(0.05)` calls returns it to within 0.005 of 0.56.

CharacterView (model: a `THREE.Group`; clips: a Map with `idle` and `walk`
= `new THREE.AnimationClip(name, 1, [])`):
10. a Map without `walk` throws an Error whose message contains "walk".

12. first `setFacing(1)` snaps `root.rotation.y` to 1; then `setFacing(2)` +
