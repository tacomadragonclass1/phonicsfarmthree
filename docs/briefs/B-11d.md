## `colliders.ts`
```ts
/**
 * Build the physics description for one placed model.
 * @param id       entity id
 * @param spec     the model's ColliderSpec from the manifest
 * @param object   the placed scene object (already positioned/rotated in the world)
 * @param layer    Layer.* value
 * @param blocksCamera from the manifest
 * @returns null when spec.kind is 'none'
 */
export function staticFromSpec(id: string, spec: ColliderSpec, object: THREE.Object3D, layer: number, blocksCamera: boolean): StaticOptions | null

/** Flatten every Mesh under `object` into world-space triangles. */
export function worldTriangles(object: THREE.Object3D): { vertices: Float32Array; indices: Uint32Array }
```
- Call `object.updateWorldMatrix(true, true)` first.
- **box / cylinder**: the spec's `offset` is in the model's LOCAL space.
  World position = object world position + offset rotated by the object's
  world yaw (rotation about +Y only; assume no tilt) and scaled by the
  object's world scale. `yaw` in the result = the object's world yaw
  (extract with `new THREE.Euler().setFromQuaternion(q, 'YXZ').y`). Box
  half extents and cylinder radius/height are multiplied by the world scale
  (assume uniform scale; use scale.x for x/z and scale.y for y).
- **trimesh**: `worldTriangles(object)`; position is {0,0,0}; no yaw.
- `worldTriangles`: for every `THREE.Mesh` (skip any with
  `userData.isOutline`), apply `mesh.matrixWorld` to each position; if the
  geometry has an index use it (offset by the running vertex count),
  otherwise generate 0,1,2,... Throw an Error if there are no triangles.
- NO Rapier import. Only three and the two type imports.

## Tests (Node)
box offset rotates with a 90-degree yaw (offset [1,0,0] on an object at
(5,0,5) turned +90 degrees about Y lands at the position three.js itself
gives for `object.localToWorld(new Vector3(1,0,0))`); scale 2 doubles half
extents; cylinder passes radius/height through; 'none' gives null; trimesh
from two meshes (one indexed, one not, one translated parent) has the right
vertex and index counts and world-space coordinates; outline meshes are
skipped; an empty group throws.
