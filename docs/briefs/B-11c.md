## What it does
One function that puts everything in the scene, registers every collider
and creates the game state. No renderer, no DOM, no input, no audio -- it
must run in Node.

```ts
export const SLICE_LAYOUT = {
  playerStart: { x: 0, z: -3 },
  cottage: { x: -6, z: 7, yaw: Math.PI },
  trees: [{ x: 7, z: 6 }, { x: -9, z: -1 }, { x: 9, z: -5 }],
  blocks: [
    { id: 'block-s', letter: 's', x: -2.2, z: -0.5 },
    { id: 'block-a', letter: 'a', x: 2.4, z: -1.5 },
    { id: 'block-t', letter: 't', x: 3.4, z: 2.5 },
  ],
  pedestals: [
    { id: 'stump-1', x: -1.6, z: 3 },
    { id: 'stump-2', x: 0, z: 3 },
    { id: 'stump-3', x: 1.6, z: 3 },
  ],
} as const;

/** Stump size, measured on the models: post + cap. */
export const PEDESTAL = { radius: 0.69, height: 0.61 } as const;

export interface SliceWorld {
  lighting: LightingRig;
  player: { body: CharacterBody; view: CharacterView };
  blocks: BlockState[];
  pedestals: PedestalState[];
  blockViews: Map<string, BlockView>;        // by block id
  pedestalViews: Map<string, PedestalView>;  // by pedestal id
  /** Every view, for the per-frame update(dt). */
  update(frameDt: number): void;
}

export function buildWorld(deps: {
  scene: THREE.Scene;
  library: AssetLibrary;          // already loaded
  physics: PhysicsWorld;
  letters: LetterTextureCache;
}): SliceWorld
```

Steps, in this order:
1. `createLightingRig()`; add its group to the scene; `scene.fog = createFog()`.
2. **Terrain**: `library.instantiate('terrain')` at the origin, `applyLook`
   with `{ outline: false }`, add to scene, register with
   `staticFromSpec('terrain', MODELS.terrain.collider, object, Layer.World, true)`.
   Everything after this is placed ON the ground with the helper
   `groundY(x, z) = physics.groundHeight(x, z, 6) ?? 0`.
3. **Cottage and trees**: instantiate, set position (x, groundY, z) and
   `rotation.y`, `applyLook`, add to scene, register via `staticFromSpec`
   with `Layer.World` and the manifest's `blocksCamera` (ids `cottage`,
   `tree-0`, `tree-1`, ...). Skip registration when it returns null.
4. **Pedestals**: state `{ id, position: {x, y: groundY, z}, snapHeight: PEDESTAL.height, blockId: null }`.
   View from `library.instantiate('pedestalPost')` and `('pedestalCap')`
   (both through `applyLook`). Add `view.root` to the scene. Collider:
   cylinder radius/height from `PEDESTAL`, centre at
   `y = groundY + PEDESTAL.height / 2`, `Layer.Pedestal`, id = pedestal id.
5. **Blocks**: state `{ id, letter, position: {x, y: groundY, z}, carried: false, pedestalId: null, silentDrops: false }`.
   Model `library.instantiate('block')` through `applyLook`; a
   `new LetterFaces(letters)`; a `BlockView`. Add `view.root` to the scene,
   call `view.syncFromState()`. Collider: box half extents 0.4, centre
   `y = position.y + 0.4`, `Layer.Block`, id = block id. Export the helper
   `blockColliderCentre(position: Vec3): Vec3` (adds 0.4 to y) -- main.ts
   reuses it when a block is put down.
6. **Player**: `physics.createCharacter({ x, y: groundY + 0.1, z })`;
   `CharacterView` from `library.instantiate('chuck')` (through `applyLook`)
   and `library.get('chuck').clips`. Add `view.root` to the SCENE directly
   (it carries a world yaw).
7. **Shadows**: for every mesh under each model, `receiveShadow = true` and
   `castShadow = MODELS[id].castsShadow`, except meshes with
   `userData.isOutline` (never cast, never receive).
8. `update(frameDt)` calls `update` on every block, pedestal and character view.

Do not move `view.root` of a block yourself anywhere else: `syncFromState`
owns that.

## Tests (Node)
Use a real `PhysicsWorld` and an `AssetLibrary` constructed with
`{ baseUrl: '/', loader: fake }` where the fake `loadAsync(url)` returns a
small scene per url: the terrain is one flat indexed quad mesh 26 x 26 m at
y = 0 with a `MeshStandardMaterial` that has a `DataTexture` map; the block
has meshes named Cube, Front, Back, Left, Right, Top; chuck is a Group with
one Mesh and two `AnimationClip`s named `idle` and `walk` (empty tracks);
the rest are single box meshes. `LetterTextureCache` gets a fake canvas
factory (see `tests/letterFaces.test.ts` for one).
- three blocks, three pedestals, views for each, all roots in the scene;
- each block's root.position equals its state position and y is 0 (the flat ground);
- `physics.canReach` straight through a block's centre is false, and true
  with that block's id ignored (the collider is registered under the block id);
- `physics.isBoxClear` at a pedestal centre is false;
- the player body settles to grounded within 120 steps of `move(0,0,1/60)` + `physics.step(1/60)`;
- the character root's parent is the scene;
- outline meshes do not cast shadows; the terrain mesh does not cast and does receive.
