## What it is
`CarryRules` decides what Chuck is holding and what the action button does.
It owns no rendering and no physics. It is told where Chuck is each step and
answers through events. Implement the rules below exactly.

```ts
export interface CarryRulesOptions {
  world: WorldQuery;
  blocks: BlockState[];          // live array; entries may be added/removed later
  pedestals: PedestalState[];
  activatables?: Activatable[];  // e.g. the bell
}

export class CarryRules implements EventSource<CarryEvents> {
  constructor(options: CarryRulesOptions);
  readonly carried: BlockState | null;       // getter
  /**
   * Call once per simulation step.
   * @param position Chuck's feet (bottom-centre), world space.
   * @param heading  unit horizontal direction he is TRAVELLING (not drawn).
   * @param action   true on the step the action was pressed.
   */
  step(position: Vec3, heading: { x: number; z: number }, action: boolean): void;
  /** Forget a carried block without dropping it (it was consumed elsewhere). */
  releaseCarried(): void;
  on(...)  // from EventSource<CarryEvents>
}
```
Use `Emitter` from `src/core/Emitter.ts` and helpers from `src/core/math.ts`.
All tunables come from `PlayerTuning` in contracts -- do not retype numbers.

## The rules
Each `step`:
1. If `action` is true -> run **interact** (below) and do nothing else.
2. Else if nothing is carried -> run **pickup by touch**.

**Pickup by touch.** First, forget the "just released" block if it is gone
from `blocks`, is carried, or is farther than `releaseDistance`
(horizontally) from Chuck. Then among blocks that are not carried, not on a
pedestal, and not the just-released block, take the NEAREST one whose
horizontal distance is `< touchPickupDistance` and which is reachable. Pick
it up: `carried = true`, `pedestalId` stays null, emit `pickedUp`.

**Reachable(target position, ignoreIds)** =
`world.canReach(chuck + {y: reachFromHeight}, target + {y: reachToHeight}, ignoreIds)`.
For a block, `ignoreIds` is the block's own id plus the id of the pedestal it
sits on (if any). For a pedestal or activatable, its own id.

**Interact while carrying.**
- Find the nearest EMPTY pedestal within `interactionDistance` that is
  reachable, and the nearest activatable within `interactionDistance` that
  is reachable.
- If there is an activatable and (no pedestal, or the activatable is
  strictly nearer than the pedestal): call `activate()` and stop.
- Else if there is a pedestal: place the block. `carried = false`,
  `block.pedestalId = pedestal.id`, `pedestal.blockId = block.id`,
  `block.position = pedestal.position + {y: snapHeight}`, emit `placed`.
- Else: try to **drop**.

**Drop.** For each angle in `PlayerTuning.dropAngles` (degrees, in order):
rotate `heading` about +Y by that angle (use `rotateY`), scale by
`dropDistance`, add to Chuck's x/z. `y = world.groundHeight(x, z, chuck.y + 0.15)`;
if null, skip this spot. The block would rest at `y + 0.02`.
Skip the spot unless
`world.isBoxClear({x, y: rest + 0.4, z}, dropHalfExtents, [block.id])`.
Skip it unless `world.canReach(chuck + {y: 0.4}, {x, y: rest + 0.4, z}, [block.id])`.
First spot that survives: `carried = false`, `position = {x, rest, z}`,
remember it as the just-released block, emit `dropped`, stop.
If no spot survives Chuck keeps the block and nothing is emitted.

**Interact with empty hands.**
- Find the nearest block that IS on a pedestal, within `interactionDistance`,
  reachable. Find the nearest reachable activatable within
  `interactionDistance`.
- If there is an activatable and (no such block, or the activatable is
  strictly nearer): `activate()` and stop.
- Else if there is a block: clear both references (`pedestal.blockId = null`,
  `block.pedestalId = null`), emit `removed`, then `carried = true`, emit
  `pickedUp`.
- Loose blocks are NEVER picked up by the action. Only by touch.

Only one block can be carried. "Nearest" always means horizontal distance.

## Tests (at least these)
- walking within 0.95 m picks up; at 1.0 m does not; nearest of two wins
- an unreachable block is not picked up
- a block on a pedestal is NOT picked up by touch, only by action
- drop lands 1.12 m ahead along the heading at ground height + 0.02
- after a drop the block is not re-picked until Chuck is > 1.5 m away,
  then it is
- drop tries the next angle when the front is blocked (assert the position
  for 45 degrees), and keeps the block when all eight fail
- drop skips a spot with no ground
- place on the nearest empty pedestal; occupied pedestal is ignored
- retrieve from pedestal with action; both references cleared; events in
  order `removed` then `pickedUp`
- activatable beats pedestal only when strictly nearer; works empty-handed
  and while carrying
- `releaseCarried` empties the hands with no event
- the action step does not also touch-pickup in the same step
