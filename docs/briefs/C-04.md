## 1. `Chime.ts` -- a synthesised bell (there is no bell recording)
```ts
/** The few AudioContext members used, so a fake can stand in for tests. */
export interface ChimeContext { currentTime: number; createOscillator(): OscLike; createGain(): GainLike }
export function playChime(context: ChimeContext, destination: unknown, options?: { frequency?: number; duration?: number; volume?: number }): void
```
Three sine partials at `f`, `2.76 f` and `5.4 f` (default f = 660 Hz) with
gains 1, 0.45, 0.2 times `volume` (default 0.25); each through its own gain
node with `setValueAtTime(g, now)` then
`exponentialRampToValueAtTime(0.0001, now + duration)` (default 1.6 s; the
upper partials use 0.6 and 0.35 of the duration); oscillators `start(now)`
and `stop(now + duration)`. Define `OscLike` / `GainLike` with only the
members you call. Test with a fake context: three oscillators created,
frequencies right, each started and stopped once.

`AudioEngine`: add `chime(frequency?: number): void` that calls
`playChime(this.context, this.master, { frequency })` (cast with a one-line
comment if the structural types need it) and does nothing when disposed.
