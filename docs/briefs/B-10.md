# Task B-10: letter faces for the alphabet block

Read `AGENTS.md` first. Follow it exactly.

The block model has six nodes: `Cube` (textured body) and five flat cream
face meshes `Front` (+Z), `Back` (-Z), `Right` (+X), `Left` (-X), `Top` (+Y).
Letters are NOT in the model: they are drawn at runtime, one lowercase
letter on each of the five faces, dark ink on cream. The font is Fredoka
weight 600 (its `a` is single-storey -- that is a requirement, never swap
the font or fake the glyph).

## Files you own
- `src/world/LetterTexture.ts`
- `src/world/LetterFaces.ts`
- `tests/letterFaces.test.ts`

## `LetterTexture.ts`
```ts
/** Minimal 2D canvas surface -- injected so this runs in Node tests. */
export interface CanvasLike { width: number; height: number; getContext(type: '2d'): Ctx2DLike | null }
export interface Ctx2DLike { /* only the members you actually use */ }
export type CanvasFactory = (size: number) => CanvasLike;

export class LetterTextureCache implements Disposable {
  constructor(options: { createCanvas: CanvasFactory; fontFamily?: string; fontWeight?: number; size?: number; ink?: string });
  /** One texture per letter, created on first use and reused. */
  get(letter: string): THREE.CanvasTexture;
  dispose(): void;
}
/** Wait until the web font is usable before any texture is drawn. */
export async function loadLetterFont(url: string, family?: string, weight?: number): Promise<void>
```
- Defaults: family 'Fredoka', weight 600, size 256, ink '#2a211c'.
- `get` accepts exactly one character a-z (case-insensitive, stored
  lowercase); anything else throws `RangeError`.
- Drawing: transparent background; `font = "<weight> <0.78*size>px <family>"`;
  `textAlign = 'center'`; `textBaseline = 'alphabetic'`. Centre the glyph
  OPTICALLY on the x-height band so that letters with ascenders and
  descenders share one baseline across blocks: put the baseline at
  `0.66 * size` for every letter (do not centre each glyph's own bounding
  box -- `a` and `b` and `g` side by side must sit on the same line).
- Texture: `colorSpace = SRGBColorSpace`, `anisotropy = 4`,
  `generateMipmaps = true`, `needsUpdate = true`.
- `loadLetterFont` uses the `FontFace` API and `document.fonts.add`; guard
  for their absence (Node) by resolving immediately.

## `LetterFaces.ts`
```ts
export const FACE_NAMES = ['Front', 'Right', 'Back', 'Left', 'Top'] as const;
export interface FacePlacement { position: [number, number, number]; rotation: [number, number, number] }  // Euler XYZ, radians
/** Where each letter decal sits, in the block's local space (origin at the bottom centre). */
export function facePlacements(options?: { half?: number; centreY?: number; lift?: number }): Record<(typeof FACE_NAMES)[number], FacePlacement>
export class LetterFaces implements Disposable {
  constructor(cache: LetterTextureCache, options?: { size?: number });
  readonly group: THREE.Group;          // add this to the block
  setLetter(letter: string): void;
  dispose(): void;
}
```
- `facePlacements` defaults: half 0.4178 (face plane distance from the
  centre axis, measured on the model), centreY 0.4847, lift 0.002 (decals sit
  just proud of the face to avoid z-fighting).
  - Front: position (0, centreY, +half+lift), rotation (0, 0, 0)
  - Right: position (+half+lift, centreY, 0), rotation (0, +PI/2, 0)
  - Back: position (0, centreY, -half-lift), rotation (0, PI, 0)
  - Left: position (-half-lift, centreY, 0), rotation (0, -PI/2, 0)
  - Top: position (0, centreY+half+lift, 0), rotation (-PI/2, 0, 0)
    (the top letter's "up" points toward -Z, so it reads upright to a viewer
    standing on the +Z side looking down).
- Five `Mesh`es sharing ONE `PlaneGeometry(size, size)` (default size 0.62)
  and ONE `MeshBasicMaterial` per LetterFaces instance:
  `{ map, transparent: true, alphaTest: 0.5, depthWrite: false, toneMapped: false }`
  with `polygonOffset` enabled (factor -1, units -1). Using alphaTest keeps
  the letters out of the sorted transparent pass.
- `setLetter` swaps the material's map from the cache. Meshes neither cast
  nor receive shadows. `renderOrder = 1`.
- `dispose` disposes the geometry and material, NOT the cached textures.

## Tests (Node; fake canvas that records calls)
cache returns the same texture for 'a' and 'A'; different for 'b'; rejects
'', 'ab', '1'; the font string contains the weight and family; baseline y
is identical for 'a', 'b', 'g'; five meshes with the five names; each face
normal (the plane's +Z rotated by its Euler) points away from the block
centre; the Top face's local +Y maps to world -Z; setLetter changes the map
on the shared material; dispose leaves cached textures undisposed.
