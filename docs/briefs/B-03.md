## `AssetLibrary implements Disposable`
```ts
export class AssetLoadError extends Error { readonly id: string; readonly url: string; readonly cause: unknown }

export interface LoadedModel {
  readonly id: ModelId;
  /** The pristine loaded scene. Never add this to the world; use instantiate(). */
  readonly scene: THREE.Group;
  readonly clips: ReadonlyMap<string, THREE.AnimationClip>;
}

/** Anything with the shape of GLTFLoader.loadAsync -- injected for tests. */
export interface GltfLoaderLike { loadAsync(url: string): Promise<{ scene: THREE.Group; animations: THREE.AnimationClip[] }> }

export class AssetLibrary {
  constructor(options?: { baseUrl?: string; loader?: GltfLoaderLike });   // loader defaults to a real GLTFLoader
  /** Load the given models (deduplicated, in parallel). `onProgress(done, total)`. */
  load(ids: readonly ModelId[], onProgress?: (done: number, total: number) => void): Promise<void>;
  has(id: ModelId): boolean;
  get(id: ModelId): LoadedModel;                     // throws if not loaded
  /**
   * A fresh copy for the scene graph. Skinned models are cloned with
   * SkeletonUtils.clone so each copy has its own skeleton; others with
   * `.clone(true)`. Geometry and textures are SHARED between copies;
   * materials are shared too (callers that recolour must clone a material
   * themselves).
   */
  instantiate(id: ModelId): THREE.Group;
  dispose(): void;                                   // disposes geometries, materials, textures once each
}
```
Rules:
- A model is fetched at most once even if `load` is called twice
  concurrently with the same id (cache the promise).
- After loading, verify every clip name in `MODELS[id].clips` exists; if one
  is missing reject with `AssetLoadError` whose message names the model and
  the missing clip.
- ANY failure rejects with `AssetLoadError` naming the id and the url. Never
  substitute a placeholder mesh. A failed id may be retried by calling
  `load` again.
- On load, walk the scene once: set `castShadow` from the manifest on every
  mesh and `receiveShadow = true`; set every texture's `anisotropy` to 4.
  Do NOT change materials, colours or colour spaces here -- that is another
  module's job.
- `url` passed to the loader is `baseUrl + MODELS[id].url`; default baseUrl
  is `import.meta.env.BASE_URL` read inside the constructor default (so the
  class still works in Node when a baseUrl is passed).
