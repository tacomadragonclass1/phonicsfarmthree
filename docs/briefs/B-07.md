## `PhysicsWorld implements WorldQuery, CameraProbe, Disposable`
```ts
export type StaticShape =
  | { kind: 'box'; halfExtents: [number, number, number] }
  | { kind: 'cylinder'; radius: number; height: number }
  | { kind: 'trimesh'; vertices: Float32Array; indices: Uint32Array };   // already in world space

export interface StaticOptions {
  id: string;                 // entity id, used by ignoreIds
  shape: StaticShape;
  position: Vec3;             // centre of the box/cylinder; ignored for trimesh
  yaw?: number;               // rotation about +Y, radians
  layer: number;              // one of Layer.*
  blocksCamera?: boolean;     // default false
}

export class PhysicsWorld {
  static async create(): Promise<PhysicsWorld>;   // awaits RAPIER.init(), gravity 0 (nothing is dynamic)
  addStatic(options: StaticOptions): void;        // fixed collider; throws on a duplicate id
  remove(id: string): void;                       // no-op if unknown
  /** Move an existing box/cylinder collider (a block being put down). */
  setPosition(id: string, position: Vec3): void;
  /** Enable/disable a collider without removing it (a carried block). */
  setEnabled(id: string, enabled: boolean): void;
  createCharacter(position: Vec3): CharacterBody; // capsule radius 0.3, total height 1.33, Layer.Player
  step(dt: number): void;
  // WorldQuery + CameraProbe exactly as documented in contracts.ts
  dispose(): void;
}
```
Details:
- Collision groups: membership = the collider's `layer`; every collider
  filters against all four layers. Query filtering by layer is done by
  passing the right `filterGroups` (read interaction_groups.d.ts) or with a
  `filterPredicate` on the collider handle -- whichever the declarations
  support. `ignoreIds` is implemented with the predicate.
- `canReach`: ray from `from` to `to` against World|Block|Pedestal. True if
  no hit before the end point, or every hit belongs to an ignored id.
- `groundHeight`: ray straight down from (x, fromY, z), max 8 m, against
  World only. Returns the hit y or null.
- `isBoxClear`: `intersectionsWithShape` with a cuboid against
  World|Player|Block|Pedestal minus ignoreIds.
- `sweep` (CameraProbe): `castShape` with a ball of `radius` from `from`
  toward `to`, against colliders flagged `blocksCamera` only. Return
  hitDistance / totalDistance clamped to [0, 1], or 1 if clear or if the two
  points coincide.
- Queries must see colliders added in the same step: after any add / remove /
  move / enable call, make sure the query structures are up to date before
  the next query (see what the installed version requires -- e.g. a
  `world.step()` with dt 0 or an explicit update call; find it in world.d.ts
  and say in your report which one you used).

## `CharacterBody`
```ts
export class CharacterBody {
  readonly position: Vec3;            // feet (bottom-centre); updated by move()
  readonly velocity: Vec3;            // actual velocity achieved last move
  readonly grounded: boolean;
  /**
   * Walk. `wishX`/`wishZ` is the desired horizontal direction * strength
   * (length <= 1). Accelerates toward wish * PlayerTuning.walkSpeed at
   * PlayerTuning.acceleration, applies a constant -1 m/s stick-to-ground
   * speed when grounded and 20 m/s^2 gravity when not, then moves through
   * the KinematicCharacterController.
   */
  move(wishX: number, wishZ: number, dt: number): void;
  teleport(position: Vec3): void;     // zeroes velocity
}
```
Controller settings: offset 0.02; up = +Y; max slope climb 45 degrees; min
slope slide 50 degrees; autostep max height 0.25, min width 0.2, dynamic
bodies false; snap to ground 0.2. The character collides with World, Block
and Pedestal layers. Use a kinematic position-based body and
`setNextKinematicTranslation`; `position` is derived from the body
translation minus half the capsule height.

## Tests (real Rapier, Node)
Build a flat ground as a big thin box (top at y = 0) unless stated.
- groundHeight returns ~0 over the ground, null off its edge, and does not
  see a platform ABOVE fromY
- canReach is false through a wall box, true around it, true when the wall's
  id is ignored
- isBoxClear false when overlapping a block collider, true after
  setEnabled(id, false), true after remove
- sweep returns ~0.5 when a camera-blocking box sits half way, 1 when the
  box is not camera-blocking
- character dropped at y = 1 lands on the ground and reports grounded
- walking +X for 2 s on flat ground reaches walkSpeed (within 2%) and covers
  roughly 12 m; stopping the wish decelerates to 0
- walking into a wall stops at the wall (x never exceeds wall face - radius)
  and `velocity.x` falls to ~0
- walks up a 20-degree ramp built as a trimesh (two triangles) and gains
  height; does NOT climb a 60-degree one
- steps over a 0.15 m high box lip but not a 0.6 m one
- teleport moves it and zeroes velocity
