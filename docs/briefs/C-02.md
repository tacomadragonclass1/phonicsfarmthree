## `WordRules`
```ts
export class WordRules implements EventSource<WordEvents>, Disposable {
  constructor(options: {
    /** Ordered left to right. */
    pedestals: readonly PedestalState[];
    /** Live array of every block. */
    blocks: readonly BlockState[];
    sound: SoundPlayer;
    isWord?: (letters: string) => boolean;   // default: the one in words.ts
  });
  /** True from ring() until the sounds finish or are cut off. */
  readonly sounding: boolean;
  /** The bell was rung. */
  ring(): void;
  on(...): Unsubscribe;
  dispose(): void;      // unsubscribes from the sound player
}
```
Behaviour:
- `ring()` while `sounding` does nothing.
- Collect the FILLED pedestals in order (a pedestal is filled when its
  `blockId` names a block in `blocks`). None filled => emit
  `nothingToSound` and stop.
- Otherwise remember that list, set `sounding`, and call
  `sound.playSequence(letters)` with the letters in order.
- While sounding, each `letterStarted` from the sound player advances
  through the remembered list: emit `letterSounded` with `index`
  (0-based among the filled ones), `pedestalId`, `blockId`, `letter`.
  Ignore `letterStarted` when not sounding (other things use the same
  player) and ignore extra ones past the end of the list.
- `sequenceFinished` while sounding => `sounding = false`, then: if EVERY
  pedestal was filled and `isWord(letters)` emit `wordMade` with the word
  and the block ids in order; otherwise emit `notYet` with the letters.
- `sequenceCancelled` while sounding => `sounding = false`, emit nothing.
- Subscribe to the sound player once, in the constructor.
- IMPORTANT ordering trap: `playSequence` may emit `sequenceCancelled` for
  whatever was playing before, synchronously, during the call. Set
  `sounding = true` only AFTER `playSequence` returns... but a player may
  also emit the first `letterStarted` synchronously during the call. So:
  set a private `starting = true` before the call; treat `sequenceCancelled`
  as "not ours" while `starting` is true; treat `letterStarted` as ours
  when `starting || sounding`; after the call set `starting = false`,
  `sounding = true`.

## Tests (Node) -- write a ~25-line fake `SoundPlayer` in the test file
(built on `Emitter`, with helper methods to fire `letterStarted`,
`sequenceFinished`, `sequenceCancelled` by hand and a `played` array).
1. nothing on the row => `nothingToSound`, nothing played.
2. s-a-t on three stumps => plays ['s','a','t'].
3. three `letterStarted` => three `letterSounded` with indexes 0,1,2 and the right pedestal/block ids.
4. then `sequenceFinished` => `wordMade` { word: 'sat' } with block ids in order; `sounding` false.
5. t-s-a => `notYet` { letters: 'tsa' }.
6. only two stumps filled with a real two-stump prefix (s, a, empty) => plays ['s','a'], ends with `notYet`, never `wordMade`.
7. a gap (s, empty, t) => plays ['s','t'] and `letterSounded` reports stump-1 then stump-3.
8. `ring()` twice in a row plays once.
9. `sequenceCancelled` mid-way => no `wordMade`/`notYet`; a later ring works.
10. `letterStarted` when nothing was rung emits nothing.
11. a fake player that emits `sequenceCancelled` and then `letterStarted` synchronously inside `playSequence` still yields the first `letterSounded`.
12. `isWord('SAT')` is true; every entry of `CVC_WORDS` matches `/^[a-z]{3}$/`.
