## Events (connect once, after step 6)
- `rules.on('focusChanged', target)`: clear the previously focused view
  (`setFocused(false)`), then `setFocused(true)` on the block view or
  pedestal view of the new target (by id). `hud.setActionReady(target !== null || rules.carried !== null)`.
- `pickedUp(block)`: `physics.setEnabled(block.id, false)`;
  `blockViews.get(block.id).attachTo(player.view.carryAnchor)`;
  `sequencer.playSequence([block.letter])`.
- `dropped(block)` and `placed({ block })`:
  `physics.setPosition(block.id, blockColliderCentre(block.position))`,
  `physics.setEnabled(block.id, true)`, `view.attachTo(null)`,
  and for `placed` also `sequencer.playSequence([block.letter])`.
  For `dropped`, play the letter only if `!block.silentDrops`.
- After pickedUp / dropped / placed also refresh
  `hud.setActionReady(rules.focus !== null || rules.carried !== null)`.

## The loop -- `new FixedStepLoop({ simulate, render, onError: console.error })`
State kept between calls: `prev` and `curr` (copies of the player's
position, plain `{x,y,z}` objects), `facingYaw` (number, starts 0).

`simulate(dt)`:
1. `const s = input.sample()`.
2. `const dir = screenToWorld(s.moveX, s.moveY, rig.forwardYaw)`.
3. copy `curr` into `prev`; `player.body.move(dir.x, dir.z, dt)`; `physics.step(dt)`; copy `player.body.position` into `curr`.
4. If `Math.hypot(dir.x, dir.z) > 0.1`: `facingYaw = Math.atan2(dir.x, dir.z)`.
5. `rules.step(curr, { x: Math.sin(facingYaw), z: Math.cos(facingYaw) }, s.action)`.
6. remember `s.cameraYaw` in a variable `yawInput` for the render.

`render(alpha, frameDt)`:
1. `player.view.setPose(prev, curr, alpha)`, `setFacing(facingYaw)`,
   `setMoving(horizontal speed of player.body.velocity > 0.3)`.
2. `world.update(frameDt)`.
3. `const pose = rig.update(player.view.root.position, player.body.velocity, yawInput, frameDt)`; `applyPose(camera, pose)`.
4. `world.lighting.follow(player.view.root.position)`.
5. `renderer.render(scene, camera)`.

Resize (window `resize`, and once at start): renderer size = canvas client
size (third argument `false`), camera aspect + `updateProjectionMatrix()`,
`setInkResolution(getInkMaterial(), drawingBufferWidth, drawingBufferHeight)`.

## `src/debug.ts`
```ts
export class DebugSource implements InputSource   // adds moveX/moveY/cameraYaw it was told to hold; action is a one-shot latch
  hold(moveX: number, moveY: number, cameraYaw?: number): void;
  press(): void;
  // sample / release / dispose as the other sources
export interface DebugHook {
  readonly ready: boolean;            // true once the loop is running
  hold(moveX: number, moveY: number, cameraYaw?: number): void;
  press(): void;
  teleport(x: number, z: number): void;
  state(): { player: Vec3; grounded: boolean; facingYaw: number; focus: string | null; carried: string | null;
             blocks: { id: string; letter: string; position: Vec3; carried: boolean; pedestalId: string | null }[];
             camera: { position: Vec3; yaw: number; distance: number }; frames: number; audio: string };
}
export function installDebugHook(hook: DebugHook): void   // sets (window as unknown as { __pf: DebugHook }).__pf
```
`main.ts` builds the hook object from its own variables. `focus` is the
focused block/pedestal id; `carried` is the carried block's id; `frames`
counts render calls; `audio` is `audio.state`. `teleport` puts the player at
(x, ground height + 0.1, z) with `player.body.teleport` and copies the
position into both `prev` and `curr`.
