- `html, body { margin:0; height:100%; overflow:hidden; background:#cfdde6; touch-action:none; user-select:none; -webkit-user-select:none; overscroll-behavior:none; }`

- `.action-button`: round, `clamp(96px, 16vmin, 168px)` diameter, bottom

  `pointer-events:auto`. A simple hand/star glyph drawn with CSS or an inline
  SVG -- no text. `.is-ready` (something is lit) => full opacity and a gentle

  pressed look. Respect `prefers-reduced-motion` (no pulse).
- `.overlay`: full-screen centred panel, cream `#fff6e0` on `#2a211c` at 60%

- `.start-button`: very large (min 220x120 px) green "play" triangle button.
- `.progress`: a thick rounded bar.

## `Hud.ts`
```ts
/** The few document members used -- injected so this runs in Node tests. */
export interface DocLike { createElement(tag: string): ElLike }
export interface ElLike { /* only what you use: className, textContent, style, setAttribute, appendChild, remove, addEventListener, classList{add,remove,toggle} ... */ }

export class Hud implements Disposable {
  constructor(options: { root: ElLike; doc: DocLike; onAction: () => void });
  showLoading(done: number, total: number): void;       // progress bar, no text needed
  /** Shows the big play button; resolves when it is pressed (a user gesture -- audio can unlock). */
  waitForStart(): Promise<void>;
  showError(message: string): void;                      // stays until reload; message in plain words
  hideOverlay(): void;
  setActionReady(ready: boolean): void;                  // toggles .is-ready on the action button
  setActionVisible(visible: boolean): void;
  dispose(): void;
}
```
- The action button calls `onAction` on `pointerdown` (not click: no 300 ms
  wait, and it must work while another finger is steering). Call
  `event.preventDefault()` and `event.stopPropagation()` so the press never
  reaches the canvas.
- `aria-label="Action"` on the button; `role="status"` on the loading
  overlay; `role="alert"` on the error overlay.
- The action button is hidden until `setActionVisible(true)`.

## Tests (Node; a small fake DocLike/ElLike written in the test file)
loading creates one overlay and updates the same bar on repeat calls;
waitForStart resolves only after the start button's pointerdown and then
removes the overlay; showError replaces any overlay and sets role alert;
action button pointerdown calls onAction once and prevents default;
setActionReady toggles the class; dispose removes everything it added.
