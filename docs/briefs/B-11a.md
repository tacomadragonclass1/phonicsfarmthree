# Task B-11a: entity views (the three.js side of blocks, stumps and characters)

Read `AGENTS.md` and `src/core/contracts.ts` first. Follow AGENTS.md exactly.
Read the public API (exports and doc comments only) of:
`src/assets/AssetLibrary.ts`, `src/assets/look/applyLook.ts`,
`src/world/LetterFaces.ts`, `src/world/LetterTexture.ts`, `src/world/Bobber.ts`.

Views DRAW game state. They never decide anything.

## Files you own
- `src/world/BlockView.ts`
- `src/world/PedestalView.ts`
- `src/world/CharacterView.ts`
- `tests/views.test.ts`

Every view takes its model as a ready `THREE.Object3D` in the constructor
(the caller gets it from `AssetLibrary.instantiate` and has already run
`applyLook` on it), so tests can pass plain Groups.

## `BlockView implements Disposable`
```ts
constructor(options: { state: BlockState; model: THREE.Object3D; faces: LetterFaces })
readonly root: THREE.Group;            // add to the scene; origin = bottom centre of the block
setFocused(on: boolean): void;         // lights up + bobs
attachTo(anchor: THREE.Object3D | null): void;  // carried: reparent under the anchor; null: back to the scene parent
syncFromState(): void;                 // when not carried: root.position = state.position
update(dt: number): void;              // advance the bob
dispose(): void;
```
- `root` contains the model and `faces.group`. Call `faces.setLetter(state.letter)`.
- Focus look: the five face meshes named Front/Back/Left/Right/Top share a
  flat cream material. On construction CLONE that material once for this
  block (so blocks do not recolour each other) and assign the clone to those
  five meshes. Focused => lerp the clone's colour toward warm gold
  (1.0, 0.82, 0.30) and set a `Bobber` on the MODEL+FACES inner group
  (amplitude 0.06, frequency 1.4, spin 0) enabled; unfocused => original
  colour, bobber disabled. The bob must move an INNER group, never `root`,
  so `root.position` stays equal to the game state.
- `attachTo(anchor)`: remember the original parent the first time; when
  attached, `root.position.set(0,0,0)` and `root.rotation.set(0,0,0)` under
  the anchor. `attachTo(null)` re-adds to the remembered parent and calls
  `syncFromState()`. World yaw of a block resting anywhere is 0.

## `PedestalView implements Disposable`
```ts
constructor(options: { state: PedestalState; post: THREE.Object3D; cap: THREE.Object3D })
readonly root: THREE.Group;            // at state.position
setFocused(on: boolean): void;
update(dt: number): void;
dispose(): void;
```
- `post` sits at local y 0.25, `cap` at local y 0.56.
- Focused => the cap rises 0.05 m and pulses its scale between 1.0 and 1.06
  at 1.4 Hz; unfocused => eases back to rest in ~0.15 s.

## `CharacterView implements Disposable`
```ts
constructor(options: { model: THREE.Object3D; clips: ReadonlyMap<string, THREE.AnimationClip>; carryOffset?: [number, number, number] })
readonly root: THREE.Group;
readonly carryAnchor: THREE.Object3D;  // child of root; default offset (0, 0.9, 0.7)
/** Feed two physics states and the blend factor; draws the interpolated pose. */
setPose(prev: Vec3, curr: Vec3, alpha: number): void;
/** World yaw to face; eased at PlayerTuning.turnRate. */
setFacing(yaw: number): void;
setMoving(moving: boolean): void;      // cross-fades idle <-> walk over 0.15 s
update(frameDt: number): void;         // mixer + facing easing
dispose(): void;
```
- One `AnimationMixer` on the model; `idle` and `walk` loop. If a clip is
  missing throw an Error naming it.
- `root.rotation.y` IS the world yaw (root must be a direct child of the
  scene). Ease with `dampAngle` from `src/core/math.ts`. The first
  `setFacing` call snaps.
- `setMoving` only starts a cross-fade when the value changes.

## Tests (Node, no WebGL; build tiny fake models with named meshes)
BlockView: root follows state; focus changes the clone's colour and not the
original material; two blocks do not share the face material; bob moves the
inner group and leaves root.position alone; attach/detach round trip
restores parent and position. PedestalView: parts at 0.25 / 0.56; focus
raises the cap and it returns. CharacterView: setPose interpolates; facing
snaps first then eases along the shortest arc across the +-PI seam;
setMoving(true) twice starts one fade; missing clip throws; carryAnchor at
the offset.
